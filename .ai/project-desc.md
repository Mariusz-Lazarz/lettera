# Aplikacja - Lettera (MVP)

## Główny problem
Aplikacja rozwiązuje problem manualnego tworzenia listów motywacyjnych (cover letter) do wybranych ogłoszeń pracy bazująć na CV użytkownika za pomocą automatyzacji z AI.

## Najmniejszy zestaw funkcjonalności
- Prosty system kont użytkownika do powiązania użytkownika z dodanymi CV oraz wygenerowanych listów motywacyjnych.
- Trzy stopniowy proces tworzenia listu motywacyjnego składający się kolejno z 1. Dodanie CV ( tylko format PDF ) 2. Dodanie ogłoszenia o prace ( tylko TEXT ) 3. Wygenerowanie listu motywacyjnego za pomocą integracji z AI 
- Możliwość edycji oraz poprawek wygenerowanych listów motywacyjnych
- Możlwość pobrania CV w formacie PDF 
- Strona profilu użytkownika do przeglądania wygenerowanych listów motywacyjnych oraz dodanych CV
- Landing page aplkacji

## Co NIE wchodzi w zakres MVP
- Dodawanie innych formatów plików dla CV niż pdf
- Pobieranie listu motywacyjnego w innym formacie niż PDF
- Import ogłoszeń o prace z adresu URL
- Funkcje społecznościowe 
- Integracje z platformami 

## Kryteria sukcesu
90% użytkowników posiada dodane minimum jedno CV oraz wygenerowany mionimum jeden list motywacyjny.
